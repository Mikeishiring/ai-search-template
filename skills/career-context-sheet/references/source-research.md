# Research across selected sources

Start with the agreed work, dates, source locations and exclusions. The portable sheet is the output; it is not a source connector. Use available authorized connectors or selected local exports. Never imply that installing this skill connects an account.

## Read beyond the first matching message

1. Inventory each selected location and its actual read capabilities. Record whether it can enumerate records, search only, read replies, follow pagination, or retrieve attachments. An accessible service does not imply access to every channel or folder.
2. Search the project's supplied names, earlier names and distinctive terms across the selected locations. Keep a small query ledger. A person or project sharing a name is a lead, not an identity match.
3. Open original records, their parent context and complete available replies. Paginate until the source reports its end; record truncation, access failures and unread attachments.
4. Follow explicit links into other selected locations. Record an out-of-scope reference without following it. Ask about expanding scope only if that gap materially changes the account.
5. Look separately for standalone earlier origins and later outcomes within the agreed date range. Later use, corrections or ownership changes may appear in a different channel without replying to the original thread.
6. Reconcile authors, project identity, copied messages and revisions. Preserve the original and repost relationship. Repetition is not independent corroboration; matching names alone never merge accounts.
7. Synthesize the account only after reading the selected context. Check personal contribution, other contributors, decisions, delivery, use, later changes and uncertainty separately. Retrieve more when a consequential claim lacks support or contradicting evidence remains unresolved.

For each location, retain what was read, the dates actually covered, open pagination, blocked reads and the next useful read. A complete search is not a complete archive. A complete inventory does not prove a complete or fair interpretation.

## Spend reads where they can change the story

Read the original account and linked evidence first. Then prioritize unresolved ownership, contradictory outcomes, later corrections, missing parent context and relevant attachments. Alternate locations so one busy channel does not consume the whole budget. On a budget stop, preserve a resumable queue and the limits in the sheet.

Calendar entries establish scheduled activity, not attendance or outcomes. Code establishes implementation activity, not adoption. A person's account can support a clearly attributed self-report without independent corroboration. Keep those distinctions in both prose and agent text.

## What the bundled tests establish

The offline research runner supports explicitly selected synthetic sources, bounded pagination, nested replies, supplied aliases and optional standalone follow-up enumeration. It records out-of-scope links without reading them. The multi-source test includes two chat channels, documents, code, email and calendar records.

These are connector-contract tests using fictional data. No live connector, semantic completeness, real-world recall or private-data access is established by passing them. The current automatic reviewer is lexical; its findings remain candidates for interpretation.
