# Present a work register

Keep one reading entry point with Work, Career timeline and Interview prep views. Work includes the overview, accounts, linked skills and tools, and inspectable sources. Use one visual system and one portable packet across the views. Do not add a marketing hero, decorative pipeline or invented score.

## Composition

Use a continuous light surface, strong typographic hierarchy and shared alignment lines. Keep the overview substantial only when it adds a supported connection across accounts. Number accounts for navigation, never as a ranking. A compact export area belongs beside the overview; it must say what will be copied and which files contain private source text.

Work titles and summaries carry the page. Keep dates distinct from source capture dates. Place material limitations beside the relevant claim. Disclose detailed contribution, decisions and sources beneath the account. Skills & tools links lead to the same work, with assistance and limits retained there. A tool label alone is not a claim of proficiency. The timeline connects periods to these accounts; preparation connects questions, answers and story chapters to the same evidence.

Use a small spacing vocabulary and one edge per boundary. Avoid nested cards, decorative badges and repeated provenance paragraphs. Controls, metadata, sources and the ending use the same type and surface system. Preserve existing brand choices when supplied.

## Interaction

Search the account text and capabilities locally. Skill selection narrows accounts; it never changes their underlying facts. Empty results have a clear reset. Link navigation must reveal the destination even after filtering. Keep text readable immediately; finite icon feedback is enough for this reading surface. Reduced motion removes transitions.

Keep global navigation reachable in each view. Direct links, refresh and back/forward retain the selected period or story. Export scope is explicit: the complete document, visible work accounts or one account. Scoped work copying omits unrelated timeline and preparation. Full HTML and JSON preserve all views, sources and saved rehearsal notes; reading filters never sanitize them. Printing includes all views and restores the reading state afterward. Without JavaScript, all substantive material remains readable; hide nonfunctional controls.

## Finish

Check a sparse account, a long multi-account archive and an absent skills index. Exercise source links, filters, empty state, keyboard disclosures, clipboard fallback, downloads, reopening and print. Inspect 320, 375, 768 and desktop widths, including expanded content. Preserve exact evidence and the selected image bytes. State checks that could not run; source inspection alone is not rendered verification.
