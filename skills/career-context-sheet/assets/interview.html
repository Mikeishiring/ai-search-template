How the preparation is produced

The model reads the available context, chooses relevant work, drafts the six sections, and identifies the few questions the evidence cannot answer. A correction or new source should update the affected sections.

This file contains the resulting draft and a reusable model handoff. It does not connect to accounts or refresh itself. Use work documents only with an approved model and sources you are allowed to share.
